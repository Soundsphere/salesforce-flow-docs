# Salesforce Flow Docs Starter Kit

This is a fork of the [salesforce-flow-docs-starter-kit](https://github.com/pawel-dobrzynski/salesforce-flow-docs-starter-kit) by [Pawel Dobrzynski](https://github.com/pawel-dobrzynski). He did all the heavy lifting, I'm just adjusting it to my needs. 

To run sffd.sh you need [Salesforce CLI](https://developer.salesforce.com/tools/salesforcecli) installed on your system and a project folder created for the org you want the flow description downloaded for.
